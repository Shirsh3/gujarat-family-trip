# Gujarat Family Yatra

A lightweight, mobile-friendly itinerary dashboard for the family trip (28 Dec 2026 – 2 Jan 2027).

## Publish with GitHub Pages
This repository includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml`.

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. The workflow will deploy the site after a push to `main`. You can also run it manually from **Actions → Deploy to GitHub Pages → Run workflow**.
4. The published URL should be: https://shirsh3.github.io/gujarat-family-trip/

## Notes
- Itinerary times and road distances are estimates; check live navigation and current schedules.
- Checklist and budget are stored in browser local storage on each device. They do not sync between family members.
- Confirm train details, vehicle seating capacity, child restraint, hotel check-in and temple/show timings before departure.
